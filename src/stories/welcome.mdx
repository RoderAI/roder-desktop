# Roder Desktop UI

A browser catalog of the same React components, Geist fonts, and theme tokens used in the desktop renderer.

- **Elements** showcases the shared controls, menus, forms, overlays, and feedback states.
- **Desktop** showcases feature components and screens using local fixtures.

Use the paintbrush toolbar to switch between the desktop's light and dark themes. These previews do not start Electron or the app-server; native capabilities are either represented by local fixtures or unavailable in the browser.
